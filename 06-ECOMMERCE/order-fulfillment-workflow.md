# Order fulfillment workflow

Owner: Product/Ops cofounder (assignment pending)  
Approval status: PROPOSAL - awaiting founder review  
Last reviewed: 2026-10-08

PROPOSAL sequence; no actual order or inventory is recorded.

1. Receive an order in the authorized system; distinguish placed from paid/accepted status.
2. Validate the selected variant, service area and stock without copying personal data into Git.
3. Reserve the correct saleable unit; quarantine damaged or unverified units.
4. Pick and inspect SKU, size, design and packaging against the controlled record.
5. Pack, hand over through the verified delivery process and update status in the authorized system.
6. Reconcile payment/collection, delivery outcome, returns and inventory movements.
7. Resolve issues privately; record only anonymized themes and aggregate metrics here.

and rehearse using fictional data in a safe test environment, then separately authorize any live test needed.
