# ROGUE Brand Headquarters

Owner: Both cofounders (assignment pending)  
Approval status: FACT register and proposed operating system  
Last reviewed: 2026-10-08

ROGUE is a Tunisian apparel brand preparing to launch with hoodies. The founders aspire to
build a community, a recognizable mindset and stories around gothic-inspired streetwear.
Good quality at a fair price is a **goal**, not an established claim.

This workspace connects the two cofounders' decisions, product development, creative production,
marketing, store readiness and operations. Start with [START-HERE](START-HERE.md), then the
[dashboard](00-HQ/dashboard.md). The current priority is to document the existing hoodie prototype,
validate who it serves and collect the costs needed for a price decision.

## Six common founder workflows

1. **Run the weekly meeting:** open the [dashboard](00-HQ/dashboard.md), copy the
   [meeting template](00-HQ/weekly-meeting-template.md), make decisions and assign actions.
2. **Develop a product:** use [product onboarding](START-HERE.md#add-a-product), then fill the
   specification, sample notes and [catalog](03-PRODUCTS/product-catalog.csv).
3. **Create a campaign:** use [campaign onboarding](START-HERE.md#add-a-campaign), approve a brief,
   select a concept and schedule it in the [calendar](05-MARKETING/content-calendar.csv).
4. **Approve an asset:** compare it with the real garment, clear rights and record an
   approval using the [creative checklist](04-CREATIVE-STUDIO/approval-checklist.md).
5. **Review launch readiness:** complete the [roadmap gates](00-HQ/roadmap-90-days.md),
   [economics](07-FINANCE/unit-economics.md) and [store QA](06-ECOMMERCE/storefront-audit-checklist.md).
6. **Review results and protect work:** complete the [weekly report](09-ANALYTICS/weekly-report-template.md),
   inventory assets, check backups and run the [audit script](scripts/audit-workspace.ps1).

## Reading conventions

FACT means supplied or evidenced information. PROPOSAL means a draft choice. UNKNOWN means
the information is missing. NEEDS VALIDATION marks a hypothesis needing evidence. Blank CSV numbers
are unknown; a verified zero must be entered explicitly. No sample financial amounts are seeded.

The workspace is prepared for a private GitHub repository shared only with people invited by
the founders. No remote is created or pushed. Private GitHub and OneDrive sync do not replace
secure access management or independent media backups.
