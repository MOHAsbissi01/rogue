# Collaboration and approval rules

Owner: Both cofounders (assignment pending)  
Approval status: PROPOSAL - awaiting founder review  
Last reviewed: 2026-10-08

PROPOSAL operating rules; named owners and founder approval are pending.

Drafts may be edited locally with version history. Original assets must be preserved; significant changes
start with an impacted-path summary. Record proposal, review and actual approval separately. A filename such
as final or approved is not sufficient evidence. Keep the precise asset version/hash with each approval.

Both founders should approve positioning, identity, commercial price, production quantity, launch and spending
ceilings. Routine execution may be delegated within a recorded scope. No agent may publish, deploy, spend,
buy domains or modify live storefronts without explicit user authorization. No remote creation or Git push is authorized.

Private GitHub access should include exactly people invited by the founders, with named accounts, suitable
permissions, strong authentication and periodic removal of unused access. Do not share credentials. Before a
commit review files for secrets, personal data, rights and size. Private GitHub and OneDrive sync are not backups
or substitutes for access management. Next action: approve the collaborator list and media storage policy.
