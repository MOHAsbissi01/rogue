# Confidential supplier records boundary

Owner: Both cofounders (assignment pending)  
Approval status: PROPOSAL - awaiting founder review  
Last reviewed: 2026-10-08

This folder marks a workflow boundary, not a secure storage service. Do not put confidential documents,
identity files, signed releases, personal invoices, tokens or customer contact details into Git.
The folder's contents are ignored except this safe guide, but OneDrive may still synchronize them.

Use founder-approved restricted storage outside the repository for real records. Keep only a safe document
code, rights/status summary and expiry where needed in the main workspace. No such records have been supplied.
Next action: approve storage location, access, retention and backup before collecting sensitive documents.
