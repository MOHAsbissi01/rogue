# Break-even review

Owner: Both cofounders (assignment pending)  
Approval status: PROPOSAL - awaiting founder review  
Last reviewed: 2026-10-08

The model currently has no result because costs, price, order behavior and acquisition inputs are missing.

Fixed launch costs cover costs not already included in variable contribution. Contribution per order must
use the same offer, return assumptions and acquisition basis throughout. Under one unit per order:
**break-even units = fixed launch costs / contribution per order when contribution is positive**.
Round upward. With multiple units per order, this ratio is orders, and units require a consistent basket/mix model.

If contribution <= 0, increasing volume cannot recover fixed costs under the same assumptions. If any required
input is missing, report 'unavailable' rather than zero. Test how higher costs, refunds, delivery subsidy or CAC
change the result. A positive contribution does not establish net profitability or enough cash to fund production.

Decision worksheet: source scenario; complete inputs?; contribution before/after acquisition; fixed cost scope;
one-unit assumption or basket mix; break-even orders/units; downside; available funding; approval/deferral reason.
