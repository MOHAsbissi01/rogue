# Creative testing plan

Owner: Both cofounders (assignment pending)  
Approval status: PROPOSAL - awaiting founder review  
Last reviewed: 2026-10-08

## Prerequisites

PROPOSAL protocol. No test has run. First collect organic evidence, complete product fidelity/rights review,
fix critical store issues and establish sourced order economics. Verify event measurement manually when authorized.
Do not assume platform clicks equal product-page visits or a checkout event equals a completed order.

## Design a controlled question

Start with one comparison: hook A/B with the same body, offer and audience; then product-detail vs lifestyle
body with a constant hook; then CTA wording with the same truthful offer. Do not change every variable at once.
Record test ID, hypothesis, variants, objective, allocation, audience, observation window, primary measure,
minimum information needed, attribution method, TND loss ceiling and actual approvers before launch.

## Stop / continue rules based on actual results

- Stop immediately for misleading garment output, rights/consent failure, broken checkout or spending beyond the approved ceiling.
- Pause analysis if tracking is incomplete or sources cannot be reconciled. Repair measurement before inferring performance.
- At the predeclared review window compare like exposures and actual denominators. If volume is insufficient,
  report inconclusive. Extend only with a new approved ceiling, never automatically.
- For acquisition, compare actual CAC with the approved affordable CAC derived from contribution before acquisition,
  including returns and variable costs. If contribution after acquisition is negative, pause/revise unless founders
  explicitly approve a bounded learning loss. Break-even CAC is a ceiling, not a target.
- Continue a variant only when its primary outcome and uncertainty justify it within the remaining approved budget.
  Likes/reach alone cannot establish profitable conversion. Account for delayed orders and returns before scaling.

No universal CTR, ROAS, CAC or spend threshold is invented here. Founders set test-specific limits from economics
and the evidence available. Next action: record an actual organic comparison and define a minimal informative paid test,
if justified. Any account action remains separately authorized.
