# Product and SKU naming

Owner: Both cofounders (assignment pending)  
Approval status: PROPOSAL - awaiting founder review  
Last reviewed: 2026-10-08

PROPOSAL operating convention: `RG-H001` identifies the first hoodie record. It is not a commercial name,
variant, size or stock count. Base IDs use RG, one uppercase category letter and three digits.
Collection IDs use `DROP-001`; their codes do not promise a launch date.

Once variants are approved, use `RG-H001-CODE-SIZE`, with color and size tokens from controlled, documented
lists. CODE and SIZE here are literal schema examples, not real colorways or sizes. Do not create saleable
SKUs until the underlying garment specifications are approved. Never reuse an ID for a different product.

Store one row per product in the catalog and one row per real variant/location in inventory. Use the variant
SKU for order and stock reconciliation. Retired IDs remain traceable; do not delete their history.
Next action: approve category letters and variant dictionaries when another product or variant is ready.
