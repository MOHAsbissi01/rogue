# Creative production workflow

Owner: Brand/Growth cofounder (assignment pending)  
Approval status: PROPOSAL - awaiting founder review  
Last reviewed: 2026-10-08

PROPOSAL workflow: brief -> rights/reference check -> shot list/storyboard -> capture or authorized generation ->
select -> edit -> fidelity/claims/accessibility review -> founder approval -> authorized publish -> results review.

Keep camera originals in raw and never overwrite them. Work in a versioned editing project. Export review
versions separately; only copy a signed-off derivative into approved. Record source assets, project version,
music license, participant consent, garment reference and allowed channels.

For AI record model/tool, prompt, reference permissions, output version and known discrepancies. Do not generate
or spend through Higgsfield merely because this folder exists. A founder must authorize the actual use/spend.
Before delivery inspect the first/last frames, sound, captions, crop, garment and CTA in the intended view.
Next action: assign editor and reviewer and estimate actual workload before setting a publishing cadence.
