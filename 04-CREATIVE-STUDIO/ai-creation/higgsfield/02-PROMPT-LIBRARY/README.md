# Prompt library

Owner: Creative lead (cofounder assignment pending)  
Status: PROPOSAL - not approved; no production executed  
Last reviewed: 2026-10-08

These are model-neutral creative drafts, not executable API schemas or verified successful prompts. Fill the
production's exact shot/reference/settings fields and verify the chosen workflow before authorized use.
No prompt has been run or proven in this implementation. Review constraints are mandatory even if a tool does not
offer a dedicated negative-prompt parameter. Keep a versioned prompt per attempt in the production.

Browse text-to-video for non-product atmosphere, image-to-video for reference-led movement, product-showcase for
truthful detail, cinematic-streetwear for connected narrative, camera-movement and character-motion for concrete
action, transitions for edit continuity, sound-design for finishing cues, and image-generation for photography planning.
The parent prompt-template remains a compatible general worksheet; this library extends it rather than replacing it.
