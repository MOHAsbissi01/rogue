# Negative constraints and rejection rules

Owner: Creative lead (cofounder assignment pending)  
Status: PROPOSAL - not approved; no production executed  
Last reviewed: 2026-10-08

Default review constraints: no altered garment art, text, placement, colors, hood, sleeve graphics, fit or trims;
no invented decoration or claimed material; no changing character identity; no extra limbs, impossible contact,
fabric melting, flicker or unwanted logos; no false stock/price/quality messages; no unlicensed music or likeness.

For motion, reject frozen action when movement is specified, sliding feet, disconnected limbs, teleportation and
cuts that reverse an unmotivated direction. For editing, reject abrupt audio cuts, accidental silence, illegible
titles and a missing CTA. These are acceptance rules, not a promise that a prompt or model can enforce them.

If the selected interface supports an exclusion/negative field, adapt the relevant subset using verified syntax.
Otherwise include clear constraints in the creative brief and inspect output manually. Never hide a failed detail
with a crop that misrepresents the garment. Record the failure and choose a revised or authentic-footage route.
