# Audio production

Owner: Creative lead (cofounder assignment pending)  
Status: PROPOSAL - not approved; no production executed  
Last reviewed: 2026-10-08

Sound is a planned production department, not an optional last-minute patch. Music, location ambience, effects
and voice if relevant must reach the final mixed master. Native audio availability is UNVERIFIED for every workflow.

Assign a sound/editor owner, prepare shot-level cues and choose a lawful source before production. Keep working
effects and voice takes in local folders with backup; link canonical files in cue sheets rather than duplicating them.
No audio was generated, licensed or commissioned by this setup. A video file containing a silent audio track still
fails a planned sound requirement. Next action: select a soundtrack direction and verify permissions before use.
