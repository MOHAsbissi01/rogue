# Video production index and ID rules

Owner: Creative lead (cofounder assignment pending)  
Status: PROPOSAL - not approved; no production executed  
Last reviewed: 2026-10-08

Use the central production register for packages and deliverables register for each separately reviewable video.
HV-001 is the first-hoodie package; HV-001-A/B/C identify the three proposals. A folder suffix is descriptive,
not part of the stable production ID. New production IDs are HV- followed by three digits; never reuse a number.
Scene IDs: HV-001-A-S01. Attempt IDs: HV-001-A-S01-A001. Export revisions: v01, v02, and onward without overwrite.

Join product_id/product_sku to the product catalog, campaign_id to the campaign register, content_id to the
marketing calendar, and attempt_id to credit/cost records. One deliverable can have several actual social posts;
add destination-specific rows/content IDs at release, preserving master/variant and approval relationships.
Do not duplicate authoritative metrics: performance documents link analytics observations and source IDs.

The production-template directory is the single reusable onboarding source. Its placeholder fields are intentional;
the script renders them into the new folder and registers a proposed main deliverable plus an unscheduled calendar row.
No template is a past success. Future-productions is for notes, not registered jobs or synthetic actuals.
