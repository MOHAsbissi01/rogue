# Creative experiments

Owner: Creative lead (cofounder assignment pending)  
Status: PROPOSAL - not approved; no production executed  
Last reviewed: 2026-10-08

Use a specific hypothesis and one changed variable per comparison. Start from the same approved product reference,
story beat and output objective. Record actual workflow/settings, prompt revisions, evidence, failure categories and
credit/cost references. Test only after explicit authorization and within its limits; this setup runs no generations.

Do not call a workflow better from one attractive output. Compare fidelity, purposeful subject motion, continuity,
audio/finishing burden and cost to a reviewed deliverable. Mark insufficient or incomparable evidence clearly.
Keep failed media in ignored local storage with safe notes and hashes; do not expose identity/rights-restricted files.
