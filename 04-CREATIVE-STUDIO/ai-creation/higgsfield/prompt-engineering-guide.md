# Prompt engineering guide

Owner: Creative lead (cofounder assignment pending)  
Status: PROPOSAL - not approved; no production executed  
Last reviewed: 2026-10-08

Write for a shot within a story, not a list of cinematic adjectives. Lock the product and character references;
then describe observable actions, timing, camera, setting, light, continuity and the intended editorial handoff.

PROPOSAL prompt order: shot ID/purpose -> approved references and immutable details -> starting pose/location ->
subject action in timed beats -> camera path/framing -> end pose/direction -> light/environment -> audio intent ->
output settings verified for the chosen workflow -> exclusions -> review criteria. Do not paste private identity data.

Describe physical movement separately from camera movement: 'takes two unhurried steps and turns to face camera'
is different from 'camera slowly tracks left'. Keep motion practical for the shot length. Avoid conflicting moves
such as orbit plus whip-pan plus zoom on a single detail shot. Make entrances and exits compatible with the next cut.

Use front/back/detail references only when the verified workflow supports them. Never substitute verbal guesses
for missing art, color or fit. Record the exact prompt text/version, references and settings with every attempt.
Change one variable in an experiment, document the outcome and stop/review when fidelity remains unreliable.
Audio descriptions in a video prompt are a creative intention; they do not prove the selected model generates sound.
Negative constraints guide review and may be included where supported; they are not a provider API guarantee.
