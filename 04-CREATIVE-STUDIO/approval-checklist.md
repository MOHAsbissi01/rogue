# Creative release checklist

Owner: Brand/Growth cofounder (assignment pending)  
Approval status: PROPOSAL - awaiting founder review  
Last reviewed: 2026-10-08

No creative asset is approved by this template. Record one review per exact file version.

- [ ] Product fidelity: art placement, text, seams, silhouette, color, trims and fit match approved references.
- [ ] Claims: materials, quality, availability, price and lead time have dated supporting evidence.
- [ ] Rights: artwork, footage, location, fonts and music permit intended organic/paid use, territory and duration.
- [ ] Consent: participants agreed to the actual use; signed files are outside Git; consent code is recorded.
- [ ] Disclosure: gifted/paid collaboration or synthetic media disclosure is checked for the intended context.
- [ ] Technical: crop, legible text, sound, subtitles, spelling and CTA destination are checked on mobile.
- [ ] Approval: actual reviewer, version/hash, allowed channels, ISO date and expiry are recorded.
- [ ] Publication: explicit authorization covers this release; an approved file alone does not authorize account actions.

If any material item fails, return to editing and create a new version. Keep rejected outputs for traceability
when safe, labeled clearly. Next action: review the first two proposed concepts and define their fidelity anchors.
